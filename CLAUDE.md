# languagues_learning — App web para aprender INGLÉS
Una única app web (PWA estática) para aprender inglés nivel por nivel (empezando por A1), a RITMO LIBRE basado en dominio, sin calendario. Se publica en GitHub Pages, uso desde el celular en https://jarbit8.github.io/languagues_learning/ (instalable). Meta: inglés a nivel examen (TOEFL / IELTS para maestría en USA) — todos los exámenes internos imitan ese formato desde A1.

**SOLO INGLÉS (2026-08-29):** el curso arrancó con inglés Y francés en paralelo, porque el francés era para la vía de residencia canadiense. El usuario descartó Canadá, decidió enfocar solo inglés y pidió quitar TODO rastro del francés: se borraron los 52 packs `-fr.json`, el lado `fr` de las 782 tarjetas de vocabulario y el motor multiidioma entero del código (el tipo `Idioma`, `src/config.ts` con `IDIOMAS_ACTIVOS`/`idiomaUnico`/`nombreIdioma`/`notaVisible`, los selectores EN/FR de las pantallas, los chips de color por idioma y las voces `fr-FR`). Todo eso sigue recuperable en el historial de git (hasta el commit `82cd38b`) por si algún día quiere francés u otro idioma; volver a un curso multiidioma es un refactor, no un interruptor. NO reintroducir una dimensión de idioma sin que lo pida explícito.

STACK (no negociable): Vite + React 18 + TypeScript + Tailwind CSS, SPA 100% estática — GitHub Pages no ejecuta servidor, PROHIBIDO backend/API routes/SSR. vite.config.ts con base: '/languagues_learning/' exacto al nombre del repo. Routing con HashRouter o tabs por estado, PROHIBIDO BrowserRouter (rompe al refrescar en Pages). PWA con vite-plugin-pwa, registerType autoUpdate. Todo el progreso en IndexedDB vía Dexie, sin backend ni auth. Audio con Web Speech API (speechSynthesis): en-US con fallback en-GB, rate 0.9. IA (speaking y corrección de writing): llamadas DIRECTAS del navegador a api.anthropic.com con header anthropic-dangerous-direct-browser-access: true; la API key la pega el usuario y vive SOLO en localStorage de su dispositivo, nunca en el código. Deploy automático: push a main → GitHub Actions → Pages.

⚠️ NO importar módulos de Node (`node:path`, `node:fs`...) en `vite.config.ts`: el repo no declara `@types/node` y tsconfig incluye ese archivo, así que el build de Actions falla aunque el local pase (hay un `node_modules/@types/node` suelto en el HOME del usuario que enmascara el error). Los scripts de `scripts/*.mjs` sí pueden usarlos: están fuera del `include` de tsconfig.

SEGURIDAD (repo público): ningún secreto en código, commits ni historial. .gitignore desde el primer commit: node_modules, dist, .env*.

REGLAS DE PRODUCTO (no cambiar): 1) RITMO LIBRE — no hay días, fechas ni calendario; se avanza por dominio: estudiar tema → aprobar examen de tema → se desbloquea el siguiente. 2) El usuario marca cada palabra "aprendida" cuando decide; el examen diario evalúa EXACTAMENTE las que marcó ese día (sean 5 o 50) más los repasos SRS vencidos, sin mínimos ni máximos. 3) Cada concepto de vocabulario es UNA tarjeta: `{ id, es, texto, ejemplo, pron?, nota? }` — el significado en español, la palabra en inglés, un ejemplo A1, la pronunciación figurada y una nota opcional, con audio. 4) UI 100% en español, tono directo e informal. 5) Exámenes espejo de IELTS/TOEFL. 6) Arquitectura por data packs en /data, nada de contenido hardcodeado en componentes (el contenido vive en JSON, no en el código). 7) Ejercicios y diálogos solo usan vocabulario de temas ya desbloqueados — verificable con `npm run verificar`, hay que correrlo tras escribir contenido. 8) La app funciona offline salvo speaking y corrección de writing.

ORDEN DE CONSTRUCCIÓN: Fase 0 scaffold+PWA+deploy. Fase 1 vocabulario+examen diario. Fase 2 gramática+examen de tema. Fase 3 contenido completo+examen de bloque+final. Fase 4 speaking+listening. Fase 5 progreso+pulido. Build sin errores antes de cada push.
